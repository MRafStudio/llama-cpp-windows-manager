## Форк (ext): автономная служба-шлюз локальных LLM

Главное отличие от оригинала - Windows-служба `llama-cpp-server`:
**загрузил, настроил, установил службой, забыл.** Служба переживает перезагрузки
и не зависит от GUI.

### Что нового (относительно оригинала)
- **Служба - постоянный шлюз**: порт из настроек приложения (по умолчанию `8101`),
  доступ в LAN - по настройке «Доступность в LAN»
- **Простые имена моделей** для API (`--alias` из имени файла): `Qwen3.6-35B-A3B-UD-IQ4_NL.gguf`
  → `Qwen3.6 35B A3B UD IQ4 NL` - никаких хешей
- **GUI не конфликтует со службой**: при работающей службе приложение не поднимает
  свой шлюз, кнопки «Загрузить»/«Unload» блокируются
- **Журнал службы в реальном времени** на странице «Обзор»
- **Обновления с этого репозитория** (не с оригинала)
- **Документация на русском** + `docs/LLAMAMANAGER-SERVICE.md`

### Важно
- **Артефакты не подписаны**
  Проверяйте целостность по файлам `.sha256`.
- Актуальный код - в ветке **`agent/service`**.
